# Where your work goes

```
photos/<category>/    01 - Title [featured] [2025].jpg
videos/<category>/    01 - Title [yt=VIDEOID].jpg      (poster image + YouTube ID)
                      01 - Title.mp4 + 01 - Title.jpg  (self-hosted + poster)
branding/             portrait.png, og-cover.png
_thumbs/              generated by `npm run thumbs` — don't edit
```

Tokens: `[featured]` hero slideshow · `[wide]` spans two columns ·
`[2025]` year · `[yt=ID]` / `[vimeo=ID]` video source.

Files beginning with `_` are skipped — use that for drafts.

Full details in the README at the top level.
